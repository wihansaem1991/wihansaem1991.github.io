# wihansaem1991.github.io

Portfolio of open-source security contributions — https://wihansaem1991.github.io (English) · https://wihansaem1991.github.io/ko/ (한국어)

Edit `contributions.yaml`, then run `python3 build.py` (needs PyYAML) to regenerate `index.html` and `ko/index.html`. Only approved or merged contributions are rendered.

`python3 sync.py` (needs the gh CLI) refreshes each entry's status from GitHub, writes the evidence links (pull request, approving reviews, merge commit) to `github.json`, lists approved or merged pull requests that still need an entry, and rebuilds the pages.
